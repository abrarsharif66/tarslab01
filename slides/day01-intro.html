Foundation

Why Python for GenAI?

  • It's the lingua franca — PyTorch, Transformers, LangChain, every SDK is Python-first.
  • Readable & fast to prototype — go from idea to running code in minutes.
  • Massive ecosystem — data, ML, web, deployment, all in one language.
  • Glue for everything — call APIs, orchestrate agents, serve models.
Setup

Your workspace: VS Code · Conda · UV

🧩

Editor + Python & Jupyter extensions. Where you write and run everything.

🐍

Conda

Manages Python versions + heavyweight ML packages cleanly.

⚡

UV

Ultra-fast package & project manager — pip, but seconds not minutes.

Isolation

Virtual environments — and why they matter

Every project gets its own sandbox of dependencies, so versions never collide. This is non-negotiable in AI work.

# Conda
conda create -n genai python=3.11 -y
conda activate genai

# UV (fast alternative)
uv venv && source .venv/bin/activate
uv pip install numpy pandas streamlit
