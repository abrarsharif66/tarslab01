Getting Input from the User
Making your program interactive

What is input()?

So far, we only used print() — Python talks TO us. With input(), the user can talk BACK to Python. It pauses the program and waits for you to type something.

📞 Analogy: Imagine a receptionist at a hospital. They ask "What is your name?" and wait for you to answer. input() is exactly that — Python asks a question and waits for your answer!

How input() works

input_basic.py 
# input() pauses and waits for user to type
name = input("What is your name? ")

# Whatever the user typed is stored in 'name'
print("Hello,", name)
print("Welcome to Python!")
▶ Output (if user typed "Priya")
What is your name? Priya
Hello, Priya
Welcome to Python!
💡 The text inside input("...") is just a prompt — it tells the user what to type. The actual answer they type gets stored in the variable on the left side of =
🎮 INTERACTIVE SIMULATOR — Type your answers below!
name = input("What is your name? ")
city = input("Which city are you from? ")
print("Nice to meet you,", name, "from", city)

Type Conversion — The Critical Catch!
Why input() always gives you text, and how to fix it

The Big Gotcha with input()

input() ALWAYS returns a string (str) — even if the user types a number!

⚠️ This is the #1 beginner mistake! If you type 25, Python stores it as "25" (text), not 25 (number). You cannot do math on text!
problem.py 
age = input("Enter age: ")   # user types 18

print(type(age))    # <class 'str'> ← it's TEXT not a number!
print(age + 1)      # ERROR! Can't add number to text
▶ Output
<class 'str'>
TypeError: can only concatenate str (not "int") to str

The Fix: int() and float()

Wrap input() with int() or float() to convert the text into a number.

conversion.py 
# int() converts text to whole number
age = int(input("Enter age: "))

# float() converts text to decimal number
gpa = float(input("Enter GPA: "))

print("Age next year:", age + 1)     # now math works!
print("GPA doubled:", gpa * 2)
📌 Quick Rule: If you need the user to type a number and do math with it — always wrap with int() or float(). If it is just text (name, city, etc.) leave it as plain input().

All Conversion Functions

Arithmetic, and a few surprises

Arithmetic Operators

Python can do all standard math — plus two powerful extras that beginners often miss!

🎯 What is Modulus (%) ? Think of sharing 10 chocolates among 3 friends. Each gets 3 (that is 10 // 3 = 3), and 1 is left over (that is 10 % 3 = 1). Modulus gives you the leftover!

Real-world examples

operators.py 
# Regular math
print(15 + 8)     # 23

print(5 ** 2)     # 25 (5 squared)

Comparison Operators — Asking Yes/No Questions
These always return True or False

Python can compare values — and always answers True or False

🏫 Analogy: Think of comparison operators like a teacher checking an answer. "Is 5 equal to 5?" — Yes (True). "Is 3 greater than 10?" — No (False). Python does the same thing!
==
Equal to
5 == 5 → True
!=
Not equal
5 != 3 → True
>
Greater than
8 > 3 → True
<
Less than
2 < 9 → True
>=
Greater or equal
5 >= 5 → True
<=
Less or equal
4 <= 6 → True
⚠️ = vs == — Very common mistake!
= means "store this value" (assignment)
== means "are these equal?" (comparison)
age = 18 → stores 18 in age
age == 18 → asks "is age equal to 18?" → True or False

Comparisons in action

comparisons.py 
score = 75
pass_mark = 50

print(score > pass_mark)     # True — 75 is greater than 50
print(score == 100)         # False — 75 is not 100
print(score >= pass_mark)    # True — 75 is greater or equal to 50
print(score != 75)          # False — score IS 75

False

if / else — Making Decisions
Teaching Python to choose between two paths

What is an if statement?

An if statement lets Python make a decision. If something is True, do this. Otherwise (else), do something different.

🚦 Analogy: Think of a traffic light. IF the light is green → you drive. ELSE (red or orange) → you stop. Python works exactly the same way — it checks a condition and takes one of two actions!

How if/else flows

Program starts
Is the condition True?
YES (True)
Run the if block
NO (False)
Run the else block
Continue program

The Syntax (structure) of if/else

if_else_syntax.py 
if condition:                # line ends with colon :
    # indented code runs if condition is True
    print("Yes, condition is True!")
else:                        # else also ends with colon :
    # indented code runs if condition is False
    print("No, condition is False!")
📌 Two critical rules:
1. The if and else lines must end with a colon :
2. The code inside must be indented (4 spaces or 1 Tab). Python uses indentation to know what belongs inside the if/else block!

Real examples

pass_fail.py 
score = int(input("Enter your score: "))

if score >= 50:
    print("Congratulations! You PASSED!")
    print("Your score:", score)
else:
    print("Sorry, you did not pass.")
    print("You need", 50 - score, "more marks.")

elif — Handling Many Choices
When there are more than two possibilities

What is elif?

elif stands for "else if". It lets you check multiple conditions one by one. Think of it like a multiple-choice system — Python checks each option until one matches.

🎓 Analogy: Think of grade boundaries. If marks are 90+ → A. Else if 80+ → B. Else if 70+ → C. Else → Fail. Python checks each level from top to bottom and stops at the first one that is True!

if / elif / else — Grade Calculator

grade_calculator.py 
marks = int(input("Enter your marks: "))

if marks >= 90:
    print("Grade: A — Outstanding!")
elif marks >= 80:
    print("Grade: B — Very Good!")
elif marks >= 70:
    print("Grade: C — Good")
elif marks >= 50:
    print("Grade: D — Passed")
else:
    print("Grade: F — Failed")
📌 Key idea: Python checks from top to bottom and runs only the FIRST block that is True. As soon as one matches, it skips all the rest!
