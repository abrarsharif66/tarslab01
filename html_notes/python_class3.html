The for Loop — Repeat for Every Item
When you know exactly how many times to repeat

What is a loop and why do we need it?

Imagine you need to print "Good morning!" 100 times. Without a loop, you would write 100 print statements. With a loop, you write it once and Python repeats it!

📋 Analogy: Think of a school attendance register. The teacher calls each student's name one by one — going through the full list. A for loop does the same: it goes through a collection of items, one by one, doing something each time!

for loop with range()

range(n) generates numbers from 0 up to (but not including) n. It is the most common way to repeat something a fixed number of times.

for_range.py
# Print numbers 0 to 4
for i in range(5):
    print(i)

# range(start, stop) — from 1 to 5
for i in range(1, 6):
    print("Student number:", i)

# range(start, stop, step) — every 2nd number
for i in range(0, 10, 2):
    print(i)     # 0 2 4 6 8
▶ Output (first loop)
0 1 2 3 4
📌 Remember: range(5) gives 0,1,2,3,4 — it starts at 0 and stops BEFORE 5. If you want 1 to 5, use range(1, 6).

The while Loop — Repeat Until Done
When you don't know exactly how many times to repeat

What is a while loop?

A while loop keeps running AS LONG AS a condition is True. The moment the condition becomes False, it stops.

🎵 Analogy: Think of a song on repeat. It keeps playing WHILE you haven't pressed stop. The moment you press stop (condition becomes False), it stops. A while loop works the same way!

while loop syntax and examples

while_loop.py
# Count from 1 to 5
count = 1

while count <= 5:
    print("Count is:", count)
    count = count + 1   # IMPORTANT: update the variable!

print("Loop finished!")
▶ Output
Count is: 1 Count is: 2 Count is: 3 Count is: 4 Count is: 5 Loop finished!
⚠️ Infinite Loop — The Most Common Mistake!
If you forget to update the variable inside the loop, the condition never becomes False and the loop runs forever! Always make sure something changes each time the loop runs.

✅ Correct — count updates

count = 1
while count <= 3:
    print(count)
    count += 1  # updates!

❌ Infinite Loop — never stops!

count = 1
while count <= 3:
    print(count)
    # forgot count += 1 !

break & continue — Loop Controls
Skip an iteration or stop the loop early

break — Exit the loop immediately

break is like an emergency exit. The moment Python hits it, the loop stops completely — even if there are more items left.

🚨 Analogy: You are searching through a stack of papers for a specific document. The moment you FIND it, you stop searching. That is break — stop as soon as the job is done!
break_ex.py
for i in range(1, 10):
    if i == 5:
        print("Found 5! Stopping.")
        break           # exit loop immediately
    print(i)
▶ Output
1 2 3 4 Found 5! Stopping.

continue — Skip this iteration, keep going

continue skips the rest of the current loop iteration and jumps to the next one. The loop keeps going!

⏭️ Analogy: You are reading a book and skipping pages you have already read. You do not stop reading — you just skip that one page and continue with the next!
continue_ex.py
# Print all numbers except multiples of 3
for i in range(1, 10):
    if i % 3 == 0:
        continue        # skip multiples of 3
    print(i)
▶ Output
1 2 4 5 7 8

Lists — Storing Many Values at Once
Python's most used data structure

What is a List?

So far every variable stored ONE value. A list stores MANY values in a single variable — in order, all together.

🛒 Analogy: Think of a shopping list. Instead of having a separate sticky note for each item (milk, eggs, bread), you write them all on ONE list in order. A Python list does exactly this for data!

Creating and accessing lists

lists_intro.py
# Create a list with square brackets [ ]
fruits = ["apple", "banana", "mango", "grape"]
scores = [85, 92, 78, 96, 88]
mixed  = ["Ali", 20, True, 9.5]  # can mix types!

# Access by index (position) — starts at 0!
print(fruits[0])    # apple  (first item)
print(fruits[1])    # banana (second item)
print(fruits[3])    # grape  (fourth item)

# Negative index — count from the end!
print(fruits[-1])   # grape  (last item)
print(fruits[-2])   # mango  (second from end)

# Length of a list
print(len(fruits))  # 4

Loops + Lists = Power Combo!
The most common pattern in real Python programs

Looping through a list

A for loop can go through every item in a list automatically. This is one of the most used patterns in Python!

loop_list.py
students = ["Riya", "Ali", "Priya", "Rahul"]

# Loop through the list
for student in students:
    print("Good morning,", student)

# With index using enumerate()
for i, student in enumerate(students):
    print(i + 1, ".", student)
▶ Output (first loop)
Good morning, Riya Good morning, Ali Good morning, Priya Good morning, Rahul

Real example — Calculate class average

average.py
scores = [78, 92, 85, 67, 95, 88]
total  = 0

for score in scores:
    total = total + score

average = total / len(scores)
print("Total:",   total)
print("Average:", average)

# Find the highest score
highest = scores[0]
for score in scores:
    if score > highest:
        highest = score
print("Highest score:", highest)
