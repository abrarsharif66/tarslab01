Modules — Python's Toolboxes
Using pre-built code to save time

What is a Module?

A module is a file full of ready-made functions that someone else already wrote. Instead of building everything from scratch, you import a module and use its tools instantly. Python ships with hundreds of modules built in!

🧰 Analogy: Imagine a hardware store. You do not manufacture your own screwdriver — you buy one. Python modules are your hardware store. Need maths? Import math. Need random numbers? Import random. Already built, tested, and ready!
🔢
math
Square roots, powers, pi, floor, ceiling and more maths functions
🎲
random
Random numbers, shuffle lists, pick random items — great for games
📅
datetime
Get today's date and time, calculate time differences, format dates

Importing and using modules

modules.py
# Import the entire module
import math
print(math.sqrt(16))      # 4.0 — square root
print(math.floor(4.9))    # 4   — round down
print(math.ceil(4.1))     # 5   — round up
print(math.pi)            # 3.14159...

# Import specific functions only
from random import randint, choice, shuffle

print(randint(1, 6))      # random number 1-6 (dice roll!)
print(choice(["rock", "paper", "scissors"]))

# datetime — get today's date
from datetime import date
today = date.today()
print(f"Today is: {today}")

try / except — Handling Errors Gracefully
Stop your program from crashing on bad input

Why do we need error handling?

Real programs deal with unpredictable users. What if someone types "hello" when you ask for a number? Without error handling, Python crashes. With try/except, you catch the error and respond gracefully!

🏥 Analogy: A good hospital has an emergency plan. If something goes wrong, they do not shut down — they handle it calmly. try/except is your program's emergency plan. Try the risky thing, and if it fails, handle it calmly instead of crashing!

How try / except works

try: run this code
Did an error occur?
NO — all good
Continue normally
YES — error!
except: handle it

try / except in code

error_handling.py
# Without try/except — this crashes if user types text!
# age = int(input("Enter age: "))

# WITH try/except — handles it gracefully
try:
    age = int(input("Enter your age: "))
    print(f"Next year you will be {age + 1}")
except ValueError:
    print("That is not a valid number! Please enter digits only.")

# Multiple except blocks for different errors
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero!")

# finally — always runs, error or not
try:
    x = int("hello")
except ValueError:
    print("Caught the error!")
finally:
    print("This always runs.")
▶ Output
Cannot divide by zero! Caught the error! This always runs.
📌 Common error types:
ValueError — wrong type (e.g. int("hello"))
ZeroDivisionError — dividing by zero
IndexError — list index out of range
KeyError — dictionary key not found
Exception — catches ANY error (use as last resort)

What is OOP?
Object-Oriented Programming — modelling the real world in code

The Big Idea

Everything in the real world is an object — a car, a student, a bank account. Each object has properties (name, age, balance) and can do things (drive, study, deposit money).

OOP lets you model real-world things directly in code. You create a class (the blueprint) and then make objects (actual instances) from it.

🏠 Analogy: A class is like an architect's blueprint for a house. The blueprint defines what every house will have (rooms, doors, windows). Each actual house built from that blueprint is an object. You can build many houses from one blueprint — each a bit different but following the same design!

Class vs Object — the key distinction

📋 Class (blueprint)
class Student:
  name = ???
  age = ???
  marks = ???
  study()
  get_grade()
🧍 Object (real instance)
riya = Student()
  name = "Riya"
  age = 20
  marks = 92
  riya.study()
  riya.get_grade()
🔑 Core OOP vocabulary:
Class — the blueprint / template
Object — a real thing made from the class
Attribute — a property of the object (name, age, marks)
Method — a function that belongs to the class (study, get_grade)

Creating Classes & Objects
Writing your first class with __init__

The __init__ method — the constructor

__init__ is a special method that runs automatically when you create a new object. It sets up the object's initial data. Think of it as the "setup instructions" that run the moment a new object is born.

class_intro.py
# Define the class (blueprint)
class Student:

    def __init__(self, name, age):
        # self = the object being created
        self.name = name   # save as attribute
        self.age  = age

# Create objects (instances) from the class
riya  = Student("Riya", 20)
ali   = Student("Ali",  22)
priya = Student("Priya", 21)

# Access attributes with dot notation
print(riya.name)    # Riya
print(ali.age)     # 22
print(priya.name)  # Priya
▶ Output
Riya 22 Priya
⚠️ What is self? self refers to the specific object being created or used. When you call riya.name, Python translates that to "give me the name of the riya object". You must always include self as the first parameter in every method — Python passes it automatically!

Methods — Functions Inside a Class
Teaching your objects to do things

Adding methods to a class

Methods are functions defined inside a class. They always take self as the first parameter, which gives them access to the object's own data.

methods.py
class Student:

    def __init__(self, name, marks):
        self.name  = name
        self.marks = marks

    # Method — a function inside the class
    def get_grade(self):
        if self.marks >= 90:
            return "A"
        elif self.marks >= 80:
            return "B"
        elif self.marks >= 50:
            return "C"
        else:
            return "F"

    def introduce(self):
        grade = self.get_grade()
        print(f"Hi! I am {self.name}, I scored {self.marks} — Grade {grade}")

# Create objects and call methods
riya = Student("Riya", 92)
ali  = Student("Ali",  74)

riya.introduce()
ali.introduce()
print(riya.get_grade())   # A
▶ Output
Hi! I am Riya, I scored 92 — Grade A Hi! I am Ali, I scored 74 — Grade C A

Mini Project — Student Grade Manager
Combining everything from all 6 classes into one real program!

What we are building

A Student Grade Manager that uses a Student class, a list of student objects, loops, f-strings, error handling, and even a bit of math — all in one program. This is what a real Python mini-project looks like!

grade_manager.py
import math

class Student:

    def __init__(self, name, marks):
        self.name  = name
        self.marks = marks

    def get_grade(self):
        if   self.marks >= 90: return "A"
        elif self.marks >= 80: return "B"
        elif self.marks >= 50: return "C"
        else:                return "F"

    def report(self):
        return f"{self.name:10} | {self.marks:>3} | {self.get_grade()}"


def class_summary(students):
    total   = sum(s.marks for s in students)
    average = total / len(students)
    highest = max(students, key=lambda s: s.marks)
    lowest  = min(students, key=lambda s: s.marks)
    print(f"\nClass average : {average:.1f}")
    print(f"Highest scorer: {highest.name} ({highest.marks})")
    print(f"Lowest scorer : {lowest.name}  ({lowest.marks})")


# --- Main program ---
classroom = [
    Student("Riya",  92),
    Student("Ali",   74),
    Student("Priya", 88),
    Student("Rahul", 55),
    Student("Sneha", 97),
]

print("====== Grade Report ======")
print(f"{'Name':10} | {'Marks':>5} | Grade")
print("-" * 26)
for s in classroom:
    print(s.report())

class_summary(classroom)
