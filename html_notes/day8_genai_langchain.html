AI vs ML vs DL vs GenAI
Four words people mix up — let's untangle them

They are nested, not separate

These four terms are not rivals — they fit inside each other like Russian dolls. AI is the biggest idea, and each next term is a smaller, more specialised slice of the one before it.

AI — Artificial IntelligenceAny machine that mimics "smart" behaviour
ML — Machine LearningLearns patterns from data
DL — Deep LearningUses deep neural networks
GenAICreates NEW content
🪆 Analogy: Think of transport (AI) → cars (ML) → electric cars (DL) → self-driving electric cars (GenAI). Every inner item is still part of the bigger group, just more specialised.

What makes each one different?

TermCore IdeaEveryday Example
AIAny machine doing tasks that look "intelligent" — even with hand-written rulesA chess engine, a thermostat that reacts to temperature
MLInstead of rules, it learns from data and improves with examplesSpam filter, movie recommendations
DLML using deep neural networks (many layers) for complex patternsFace recognition, voice-to-text
GenAIDeep learning that creates new content — text, images, code, audioChatGPT, image generators, code copilots
💡 The key shift: Classic ML/DL mostly predicts or classifies ("is this spam? yes/no"). GenAI generates — it produces something brand new that did not exist before.

🔍 Predictive AI (classic ML/DL)

Looks at input → gives a label or a number.
"This email is spam." / "House price ≈ $320k."

✨ Generative AI

Looks at a prompt → creates fresh content.
"Write a poem about the sea." → a brand new poem.

🎯 Why it matters: When someone says "we use AI," ask which kind? Knowing where a tool sits in these circles tells you what it can and cannot do.

How LLMs Are Trained
Three stages that turn raw text into a helpful assistant

From "predict the next word" to "helpful assistant"

A Large Language Model (LLM) is not built in one shot. It goes through three stages, each teaching it something new — first knowledge, then obedience, then good manners.

🏫 Analogy: Training an LLM is like raising a professional. School gives general education (pre-training), job training teaches the actual role (fine-tuning), and a mentor's feedback shapes good judgement (RLHF).

The 3 stages

Pre-training — learn general knowledge The model reads a huge chunk of the internet and books, and plays one simple game over and over: predict the next token (word piece). By guessing the next word billions of times, it soaks up grammar, facts, and reasoning patterns.
Fine-tuning / Instruction tuning — learn to follow instructions The raw model knows a lot but rambles. We show it many examples of instruction → good answer so it learns to actually do what it is asked: summarise, translate, answer questions.
RLHF — align to be helpful & safe Humans rank several answers from best to worst. The model is rewarded for the answers people prefer (RLHF = Reinforcement Learning from Human Feedback), nudging it to be helpful, honest, and harmless.
💡 Token, not word: Models read text in small chunks called tokens (roughly ¾ of a word). "Predict the next token" is the heartbeat of every LLM.
🎯 Why it matters: When a model "knows" a fact, that came from pre-training. When it follows your format nicely, that is fine-tuning. When it politely refuses something harmful, that is RLHF at work.

The Evolution of LLMs
How we got from tiny text models to ChatGPT

A quick timeline

  • ~2014
    RNNs & LSTMs
    Read text one word at a time. Smart for their day, but they forgot long sentences and were slow to train.
  • 2017
    The Transformer ("Attention Is All You Need")
    Self-attention let models look at the whole sentence at once and train in parallel. This is the foundation of every LLM today.
  • 2018–2019
    BERT & GPT-2
    First big wave built on Transformers. BERT understood text deeply; GPT-2 showed surprisingly fluent generation.
  • 2020
    GPT-3
    175 billion parameters. So big it could do new tasks from just a few examples in the prompt ("few-shot learning").
  • 2022
    ChatGPT & RLHF
    Instruction tuning + RLHF turned a powerful model into a friendly, easy-to-use assistant. AI went mainstream.
  • 2023→ now
    GPT-4, Claude & multimodal models
    Bigger, more capable, and able to handle images, audio and long documents — not just text.
🚗 Analogy: RNNs were bicycles, the Transformer was the first car engine, and each new model is a faster, more capable vehicle built on that same engine.
📊 Scaling & emergent abilities: A surprising lesson of this decade — give models more data + more parameters + more compute, and brand-new skills emerge that smaller models simply did not have (like reasoning step-by-step or writing code). Bigger really did mean qualitatively smarter.

The LangChain Ecosystem
A toolkit for building real apps on top of LLMs

What is LangChain — and why use it?

An LLM on its own is just a "text in, text out" box. Real apps need more: connect to a model, write good prompts, feed in your own data, remember past messages, call tools, and chain steps together. LangChain gives you ready-made building blocks for all of that, so you do not reinvent the plumbing.

🧱 Analogy: LangChain is the LEGO set / glue for LLM apps. The LLM is one special brick; LangChain gives you all the other bricks (prompts, memory, data, tools) and a simple way to click them together.

The main pieces

ComponentWhat it does
ModelsA unified way to talk to any LLM / Chat model (OpenAI, Anthropic, and more)
PromptsReusable prompt templates with placeholders you fill in at runtime
Chains / LCELPipe steps together (prompt → model → parser) using the LangChain Expression Language
Retrievers & Vector storesSearch your own documents and feed relevant chunks to the model (the heart of RAG)
MemoryRemember earlier turns so a chatbot keeps context across a conversation
Agents & ToolsLet the LLM decide which tools to call (search, calculator, APIs) to reach a goal
LangSmithDebug, trace, and evaluate your LLM app — see exactly what happened on each step
LangServeTurn a chain into a deployable web API with a few lines
💡 Big picture: Build with the core library, observe with LangSmith, ship with LangServe. Together they cover the whole journey from idea to production.
🎯 Why it matters: You will rarely call a raw LLM API in a serious app. LangChain's blocks save you weeks of plumbing and let you swap models, data sources, and tools without rewriting everything.

Setup & Your First LangChain App
Install, add your key, and send your first prompt

Step 1 — Install the packages

LangChain is modular: install the core library plus the provider package you want to use.

terminal
# Core library + the OpenAI integration
pip install langchain langchain-openai

# Optional: the Anthropic (Claude) integration too
pip install langchain-anthropic

Step 2 — Set your API key (safely!)

Your API key is like a password to a paid service. Store it as an environment variable or in a .env file — never paste it directly into your code.

.env
# .env file — keep this OUT of git (.gitignore it!)
OPENAI_API_KEY=sk-your-secret-key-here
ANTHROPIC_API_KEY=sk-ant-your-secret-key-here
⚠️ Never hardcode your key! Do not write api_key="sk-..." in your code or push it to GitHub. Leaked keys get stolen and can run up huge bills. Always load keys from the environment or a .env file.

Step 3 — Your first app: send a prompt, print the reply

A minimal program: load the key, build a chat model, send a message, and print what comes back.

first_app.py
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()              # reads OPENAI_API_KEY from .env

# 1) Build a chat model
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 2) Send a prompt
response = llm.invoke("Explain GenAI to a 10-year-old in one sentence.")

# 3) Print the reply
print(response.content)
▶ Output
GenAI is like a super-smart robot friend that can make up brand-new stories, pictures, and answers all by itself after reading tons of books.

Swap to Claude in one line

Because LangChain gives every model the same .invoke() interface, switching providers is almost a copy-paste.

use_claude.py
from langchain_anthropic import ChatAnthropic

# Same .invoke() interface — just a different model class
llm = ChatAnthropic(model="claude-sonnet-4-5")
print(llm.invoke("Say hi in 3 words.").content)
🎯 The superpower: The rest of your app does not change — same prompts, same chains. You can swap OpenAI ↔ Claude ↔ others just by changing the model line. That flexibility is a big reason teams choose LangChain.
✅
You can now build! Install → set key safely → ChatOpenAI/ChatAnthropic → .invoke() → print. That is the skeleton of every LangChain app.
