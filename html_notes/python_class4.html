What are Functions?
Reusable blocks of code with a name

The Problem Functions Solve

Imagine you need to greet 5 different students. Without functions you write the same 3 lines 5 times. That is 15 lines of repeated code. With a function, you write 3 lines ONCE and just call the function 5 times!

☕ Analogy: Think of a function like a coffee vending machine. You press a button (call the function), it does its job (runs the code), and gives you coffee (returns a result). You do not need to know HOW it makes coffee — you just press the button. You can press it as many times as you want!

Defining and calling a function

Use the def keyword to define a function. Then call it by its name followed by ().

def  greet():
    print("Hello! Welcome to Python!")

greet()     # calling the function

def keyword function name parentheses colon indented body
functions_basic.py
# Step 1: DEFINE the function (write the recipe)
def greet():
    print("Hello! Welcome to Python!")
    print("Have a great learning day!")

# Step 2: CALL the function (use the recipe)
greet()     # first call
greet()     # second call — same code runs again!
greet()     # third call
▶ Output
Hello! Welcome to Python! Have a great learning day! Hello! Welcome to Python! Have a great learning day! Hello! Welcome to Python! Have a great learning day!
📌 Two steps — always:
1. Define — write the function once with def
2. Call — run it anywhere by writing its name with ()

Parameters & Return Values
Sending data IN and getting results OUT

Parameters — Sending data into a function

A parameter is a variable inside the function that receives a value when you call it. This lets the same function work with different data each time!

🧮 Analogy: Think of a calculator. You press "5 + 3" — the numbers 5 and 3 are the inputs (parameters). The calculator uses them to compute the result. Same calculator, different numbers every time!
parameters.py
# 'name' is a parameter — a placeholder for the real value
def greet(name):
    print("Hello,", name, "!")

# "Riya", "Ali", "Priya" are ARGUMENTS — the real values
greet("Riya")
greet("Ali")
greet("Priya")

# Multiple parameters
def introduce(name, age):
    print("My name is", name, "and I am", age, "years old.")

introduce("Sneha", 20)
introduce("Rahul", 22)
▶ Output
Hello, Riya ! Hello, Ali ! Hello, Priya ! My name is Sneha and I am 20 years old. My name is Rahul and I am 22 years old.

return — Getting a result back from a function

Functions can also send back a result using return. The returned value can be stored in a variable or used directly.

🏧 Analogy: An ATM takes your card (input), processes your request, and gives you cash (return value). The return keyword is Python's way of handing the result back to you!
return_value.py
def add(a, b):
    result = a + b
    return result      # send the result back

# Store the returned value in a variable
total = add(10, 5)
print("Sum:", total)    # 15

# Use the returned value directly
print(add(100, 200))    # 300

# Practical example
def calculate_grade(marks):
    if marks >= 90:
        return "A"
    elif marks >= 80:
        return "B"
    elif marks >= 50:
        return "C"
    else:
        return "F"

print(calculate_grade(85))   # B
print(calculate_grade(47))   # F

Default parameter values

You can give parameters a default value. If the caller does not provide that argument, the default is used automatically.

default_params.py
def greet(name, message="Good morning"):
    print(message, name)

greet("Riya")                    # uses default message
greet("Ali", "Good evening")    # overrides default
▶ Output
Good morning Riya Good evening Ali

Scope — Where Variables Live
Local vs Global — why some variables are invisible

What is Scope?

Scope means where a variable can be seen and used. Variables created inside a function only exist inside that function. Variables created outside can be seen everywhere.

🏠 Analogy: Think of a house with rooms. Items INSIDE a bedroom are only available in that bedroom (local scope). Items in the LIVING ROOM are available to everyone in the house (global scope). You cannot take the bedroom TV into the kitchen!
🌍 Global Scope (whole program)
school_name = "TarsLab"
total_students = 100

← visible everywhere
📦 Local Scope (inside function)
def calculate():
  result = 42
  temp = 0

← only inside function

Scope in code

scope.py
school = "TarsLab"    # GLOBAL variable

def show_info():
    course = "Python"  # LOCAL variable — only inside here
    print(school)       # can access global variable
    print(course)       # can access local variable

show_info()
print(school)           # works fine — global
# print(course)         # ERROR! course doesn't exist here
📌 Simple rule: Variables created INSIDE a function stay inside. Variables created OUTSIDE are available everywhere. When in doubt, pass values as parameters instead of using globals!

String Methods — Text Superpowers
Built-in tools to manipulate text

Strings have built-in methods — just like lists!

Remember from Class 1 that strings are text surrounded by quotes. Python gives strings dozens of powerful built-in methods that let you search, replace, split, and transform text.

MethodWhat it doesExampleResult
.upper()ALL CAPS"hello".upper()"HELLO"
.lower()all lowercase"HELLO".lower()"hello"
.title()Title Case"hello world".title()"Hello World"
.strip()Remove spaces from both ends" hi ".strip()"hi"
.replace(a,b)Replace a with b"hello".replace("l","r")"herro"
.split()Split into a list by spaces"a b c".split()["a","b","c"]
.join(list)Join list items into a string"-".join(["a","b","c"])"a-b-c"

String methods in action

string_methods.py
name = "  riya sharma  "

print(name.strip())          # "riya sharma"
print(name.strip().title())  # "Riya Sharma"
print(name.strip().upper())  # "RIYA SHARMA"

sentence = "Python is easy and Python is fun"
print(sentence.count("Python"))          # 2
print(sentence.replace("Python", "Java")) # Java is easy and Java is fun

words = sentence.split()  # split into list
print(words)
print(len(words), "words")

# Join back with dash
print("-".join(["a", "b", "c"]))  # a-b-c

String indexing — like lists!

Strings behave like lists of characters. You can access individual characters using index numbers.

string_index.py
word = "Python"

print(word[0])    # P  (first letter)
print(word[-1])   # n  (last letter)
print(len(word))  # 6  (total letters)

# Slicing — grab a portion
print(word[0:3])  # Pyt (index 0,1,2)
print(word[2:])   # thon (index 2 to end)
print(word[:4])   # Pyth (start to index 4)
▶ Output
P n 6 Pyt thon Pyth

f-Strings — Modern String Formatting
The cleanest way to mix variables and text

The old way vs the f-string way

Before f-strings, mixing variables into text was clunky. f-strings (introduced in Python 3.6) make it clean and readable — just put an f before the quote and use {variable} inside!

Old way — clunky

print("Hello, " + name +
  "! You are " +
  str(age) + " years old")

f-string — clean!

print(f"Hello, {name}!
  You are {age} years old")

f-string examples

fstrings.py
name  = "Riya"
age   = 20
score = 87.5

# Basic f-string — put f before the quote
print(f"Hello, {name}!")
print(f"You are {age} years old.")

# Math inside curly braces!
print(f"Next year you will be {age + 1}.")
print(f"Your score is {score} out of 100.")

# Round decimal places with :.2f
price = 49.9876
print(f"Price: Rs. {price:.2f}")   # 49.99

# Call a method inside {}
print(f"Name in caps: {name.upper()}")
▶ Output
Hello, Riya! You are 20 years old. Next year you will be 21. Your score is 87.5 out of 100. Price: Rs. 49.99 Name in caps: RIYA

Putting It All Together
Functions + Strings + Everything so far

Real mini project — Name Formatter

A function that cleans up messy name input — strips spaces, fixes capitalisation, and prints a formatted ID card.

name_formatter.py
def clean_name(raw_name):
    return raw_name.strip().title()

def make_email(name):
    parts  = name.lower().split()
    return ".".join(parts) + "@tarslab.com"

def print_id_card(raw_name, course, roll):
    name  = clean_name(raw_name)
    email = make_email(name)
    print(f"====== STUDENT ID ======")
    print(f"Name  : {name}")
    print(f"Roll  : {roll}")
    print(f"Course: {course}")
    print(f"Email : {email}")
    print(f"========================")

print_id_card("  riya sharma  ", "AI Engineering", "TL001")
print_id_card("ALI khan",         "AI Engineering", "TL002")
▶ Output
====== STUDENT ID ====== Name : Riya Sharma Roll : TL001 Course: AI Engineering Email : riya.sharma@tarslab.com ======================== ====== STUDENT ID ====== Name : Ali Khan Roll : TL002 Course: AI Engineering Email : ali.khan@tarslab.com ========================
