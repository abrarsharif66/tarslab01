What is Programming?
Understanding the big picture first

Think of it like giving instructions to a very smart but very literal robot 🤖

A computer does exactly what you tell it — nothing more, nothing less. Programming is just writing those instructions in a language the computer understands.

🍳 Real-World Analogy: Imagine writing a recipe for someone who has never cooked before. You can't say "cook the pasta until it's done" — you have to say "boil 2 litres of water, add 100g pasta, wait exactly 10 minutes." Computers are like that chef — they need every detail spelled out!

Why Python?
The most beginner-friendly language in the world

Compare Python to other languages

Let's say you want to print "Hello, World!" on the screen. Here's how it looks in different languages:

print("Hello, World!")
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, World!");
  }
}
#include <iostream>
using namespace std;
int main() {
  cout << "Hello, World!" << endl;
  return 0;
}
💜 See the difference? Python is just one line. Java and C++ need 6+ lines to do the exact same thing. That's why Python is loved by beginners and professionals alike!

Your First Command: print()
Making Python talk to you

What does print() do?

print() tells Python to display something on your screen. Think of it as Python's way of speaking out loud!

📣 Analogy: Imagine print() as a megaphone. Whatever you put inside the brackets — Python shouts it out on the screen!

Basic print() examples

hello.py 
# This is your very first Python program!
# Lines starting with # are comments — Python ignores them
# They are notes for humans reading the code

print("Hello, World!")
print("My name is Abdul")
print("I am learning Python 🐍")
print(42)       # You can print numbers too!
print(3.14)     # And decimal numbers
▶ Output
Hello, World!
My name is Abdul
I am learning Python 🐍
42
3.14

Printing with Math

Python can calculate math inside print() automatically!

math_print.py 
print(5 + 3)       # Addition

print(6 * 7)       # Multiplication
print(15 / 3)      # Division
▶ Output

6

📌 Important Rules for print():

✅ Text must always be inside quotes — "like this" or 'like this'
✅ Numbers do NOT need quotes — print(42) not print("42")
❌ Don't forget the brackets! print "hello" will give an error
✅ Python is case-sensitive: print works, Print does NOT

Variables — Storing Information
Like labelled boxes that hold data

What is a Variable?

A variable is like a labelled box where you store information. You give the box a name, put something inside, and can use it later.

📦 Analogy: Think of your house. You have boxes labelled "Books", "Clothes", "Shoes". You can open any box by its name, use what's inside, or replace it with something new. Variables work exactly like this!

Creating Variables

The = sign means "store this value inside this variable". It's called the assignment operator.

variables.py 
# Creating variables
name = "Riya"          # storing text
age  = 20             # storing a number
city = "Hyderabad"     # storing text
gpa  = 8.5            # storing a decimal number

# Using variables
print(name)
print(age)
print("I live in", city)
print("My GPA is", gpa)
▶ Output
Riya
20
I live in Hyderabad
My GPA is 8.5

Variables Can Change! (That's why they're called variables)

change_variable.py 
score = 0
print("Score at start:", score)

score = 10
print("Score after level 1:", score)

score = score + 5    # add 5 to existing score
print("Score after level 2:", score)
▶ Output
Score at start: 0
Score after level 1: 10
Score after level 2: 15

Naming Rules for Variables

✅ Use letters, numbers, underscoresmy_name, score1, user_age
❌ Cannot start with a number1score ← This will give an error!
❌ No spaces allowedUse underscore instead: my_name not my name
⚠️ Case matters!Name and name are two different variables

Data Types — The 4 Main Kinds of Data
Different types of information Python understands

Just like real life has different types of things — words, whole numbers, decimal numbers, yes/no answers — Python has different data types to handle each one.

🔢
int
42, -5, 0, 1000
Whole numbers, no decimals
📊
float
3.14, 9.99, -0.5
Numbers with a decimal point
📝
str
"hello", "Riya", "123"
Text — always in quotes
⚡
bool
True, False
Only two values — yes or no!

🔢 int — Integer (Whole Numbers)

Used for counting things, ages, scores — anything that doesn't need a decimal.

int_type.py
students = 30
year = 2024
temperature = -5     # can be negative!

print(type(students))  # type() tells us the data type
▶ Output
<class 'int'>

📊 float — Floating Point (Decimal Numbers)

Used for prices, measurements, averages — anything with a decimal point.

float_type.py
price  = 99.99
height = 5.7
pi     = 3.14159

print(type(price))   # <class 'float'>
print(price * 2)    # Math works on floats too!
▶ Output
<class 'float'>
199.98

📝 str — String (Text)

Used for names, messages, sentences — any text. Always wrapped in quotes!

str_type.py
name    = "Rahul"
message = 'Hello everyone!'  # single quotes work too
number_as_text = "42"  # "42" is TEXT, not a number!

# Joining strings with +
greeting = "Good morning, " + name
print(greeting)

# String has many tricks!
print(len(name))        # length of the string
print(name.upper())    # make it UPPERCASE
print(name.lower())    # make it lowercase
▶ Output
Good morning, Rahul
5
RAHUL
rahul

⚡ bool — Boolean (True or False)

The simplest data type! Only two possible values: True or False. Used for yes/no decisions.

💡 Analogy: A light switch! It's either ON (True) or OFF (False). Nothing in between.
bool_type.py
is_student = True
has_laptop = False
is_raining = True

print(is_student)
print(has_laptop)

# Comparison gives us a boolean!
print(5 > 3)     # Is 5 greater than 3? True!
print(2 > 10)    # Is 2 greater than 10? False!
print(5 == 5)    # Is 5 equal to 5? True!
▶ Output
True
False
True
False
True

Checking Data Types with type()

type() is a built-in function that tells you what data type something is.

check_types.py
print(type(100))       # int
print(type(3.14))      # float
print(type("hello"))  # str
print(type(True))      # bool

my_var = "Python"
print(type(my_var))   # str
▶ Output
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'str'>
